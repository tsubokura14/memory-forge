# 問題づくり

問題のファイルは、このリポジトリの中で Claude Code に作らせる。人が読む作り方は `docs/questions.md`。ファイルの形と確かめることは `docs/specs/import.md` の「問題のファイル」「ファイルの確かめ」。

## 作業場所のフォルダ

- 問題のファイルは、リポジトリの `questions/` に置く。`questions/` の中のファイルは Git に入らない
- スクリプトがほかのファイルと比べるのは、`questions/` の直下の `*.json` だけ

## 問題づくりのスキル（`/make-questions`）

- 置き場所は `.claude/skills/make-questions/SKILL.md`。このプロジェクトのスキル（`CLAUDE.project.md`）
- 新しく作る：Subject・Topic・問題数と、どんな問題がほしいかを言葉で渡す。Subject・Topic・問題数のどれかが足りなければ、作る前に聞く
  - 資料（手元のファイルや URL）を渡されたら、それをもとに作る。渡されなければ、Claude の知っていることから作る
  - `questions/` がなければ作る
  - ファイルの名前は、「<Subject>-<Topic>」に書き出しのファイル名と同じ決まり（`docs/specs/manage.md`）を当てたもの（`python-decorators.json` など）。同じ名前のファイルがあれば上書きせず、終わりに `-2`・`-3`… を付ける
  - 問題の ID は空（`""`）で書き、`npm run questions:ids` で付ける
  - 書き終えたら `npm run questions:check` を走らせ、誤りがなくなるまで直す。最後に、ファイルの場所・問題数・Topic を伝える
- 書き出したファイルを直す：`questions/` のファイルと直すところを渡す
  - ID と Subject を変えない。頼まれた問題のほかは変えない
  - 問題を足すように頼まれたら、足した問題にだけ ID を付ける
  - 直したら `npm run questions:check` を走らせ、問題ごとに何をどう直したかを伝える
- 作り方のルール
  - 単一選択は、正解と言えるものが1つだけ。複数選択は、正解が2つ以上で、問題文に「すべて選べ」と分かるように書く
  - 間違いの選択肢も、ありそうなものにする。「すべて正しい」「どれでもない」は使わない
  - 解説には、正解の理由と、ほかの選択肢がなぜ違うかを書く
  - コードは ``` で囲み、言語の名前を付ける
  - 問題文と選択肢には、文の中のコード（`` ` ``）とコードブロックのほかの書き方を使わない。解説では、すべての書き方（強調・リスト・表・引用・コールアウト・数式・リンクなど）を使える
  - 確かでない事実は問題にしない。資料を渡されたときは、資料に書いてあることから作る
  - 問題文・選択肢・解説は、頼まれた言葉で書く（言われなければ日本語。コードや決まった用語はそのまま）
- 作ったファイルを、アプリに取り込まない（取り込みは Import の画面から）

## 確かめるスクリプト（`npm run questions:check -- <ファイル...>`）

- 1つ以上のファイルを、Import と同じ決まりで確かめる。誤りは Import と同じ文言で出す
- ファイルに誤りがなければ、`questions/` の中の同じ Subject のほかのファイル（確かめるファイル自身と、JSON として読めないファイル、`subject` が文字でないファイルは除く）と、ID が重なっていないかを確かめる。重なっていれば、`id` の誤り「ほかのファイル（python.json）と ID が重なっています。」にする（同じ ID が2つ以上のファイルにあるときは、先に読んだファイルの名前）
- 出力は、ファイルごとに次のどれか
  - 誤りがあるとき：「python.json：2 件の不備があります。」と、誤りごとに「  k3f9a2  correct  選択肢にありません（E）。」（ID・項目・内容）
  - 誤りがないとき：「python-decorators.json：誤りはありません（Python・10問）。」
  - ファイルを読めないとき：「python.json：ファイルを読めません。」を誤りとして出す
- 誤りが1つでもあれば、終わりのコードを 1 にする。ファイルを指定しないときは、使い方を出して 1 で終わる
- 相対パスは、コマンドを打った場所から解く

## ID を付けるスクリプト（`npm run questions:ids -- <ファイル>`）

- ID が空（`""`）か、ない問題に ID を付けて、ファイルに書き戻す。ID のある問題と、オブジェクトでない問題は変えない
- 付ける ID は、英小文字と数字の6文字のでたらめな文字列。同じファイルの ID と、`questions/` の中の同じ Subject のほかのファイルの ID と重ならない
- 書き戻す形は、2文字の字下げ、終わりに改行。ID を付けた問題は `id` がいちばん前の項目
- 出力
  - 付けたとき：「python-decorators.json：3問に ID を付けました。」
  - 付ける問題がないとき：「python-decorators.json：ID のない問題はありません。」（書き戻さない）
  - JSON として読めない・`questions` が並びでない・ファイルを読めないとき：誤りの文を出し、書き戻さずに 1 で終わる
- アプリに取り込み済みの問題の ID は見ない
