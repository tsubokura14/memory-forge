# 問題を消しても、連続日数が減らない（#90）

## なぜ

今は、問題を消すと、その問題に答えた記録も一緒に消える。その日にほかの答えがなければ、その日は取り組んだ日でなくなり、連続日数が減る。

問題の整理（Manage での削除など）をしただけで、続けてきた日数を失わないようにしたい。#10 では、消すと減ってよいことにして、あとで直すことにした。

## 影響する今の仕様

- `docs/specs/home.md` の「連続日数」：「問題を消すと、その問題の答えも数えなくなる…日数が減ることがある」
- `docs/specs/manage.md` の「削除」：「消した問題の記録も一緒に消える」と、確認のダイアログの文言（「…and their records will be deleted.」「Its records will be deleted too.」）
- `docs/specs/import.md` の「取り込んだあと」：置き換わった印の付いた問題の記録が消える（下の「決まっていないこと」）
- `docs/overview.md` の「主な機能」の「問題の削除」：「消した問題の記録も一緒に消える」

## 使う場面

1. 昨日だけ Python の問題「k3f9a2」に答え、今日はまだ答えていない人が、Manage で k3f9a2 を消す。Home に戻ると、連続日数は消す前と同じで、今週の7日の昨日も答えた日のまま
2. 10日続けて Python だけを解いてきた人が、Manage で Subject「Python」を消す。Subject が0件になっても、Home の連続日数は10のまま（今日答えていれば「done today」のまま）
3. 上の2のあと、同じ Python のファイルを取り込み直す。問題はまだ解いていない状態（「0 correct · 0 wrong · 30 new」）で出て、連続日数は10のまま

## 受け入れ条件

- Manage で Subject・Topic・1問のどれを消しても、Home の連続日数と、今週の7日の答えた日は、消す前と変わらない
  - 今日消した問題に今日答えていたなら、今日の様子は「done today」のまま
  - Subject が0件になっても、連続日数の枠は今までどおり出る
- 消した問題は、今までどおり、Manage の一覧・Home・Setup・Solve のどこにも出ない。身についている具合・正答率・解いた回数にも入らない
- 消したあとに答えていない日は、今までどおり、答えなかった日になる（消した問題の答えで、連続日数が増えることはない）
- 印の付いた問題への答えは、消したあとも数えない（印を付けたまま消した問題の答えで、連続日数が増えることはない）
- すでに消して減ってしまった日数は、戻らない

## 画面

確認のダイアログの文言を変えるかどうかで決まる（「決まっていないこと」の2）。変えるなら、Manage の次の状態の文言が変わる。

| 状態 | 表示 |
| --- | --- |
| 1問を消す | 確認のダイアログの文言 |
| Topic を消す | 確認のダイアログの文言 |
| Subject を消す | 確認のダイアログの文言 |

Home の見た目は変わらない。

## やらないこと

- 消した問題を元に戻す（ごみ箱などの）機能は作らない
- 消した問題を見る画面は作らない
- すでに消して減った日数を戻さない
- 連続日数の数え方（日本時間の0時の区切り、スキップを数える、印の付いた問題は数えない）は変えない

## 決まっていないこと

- [ ] 1. 消した問題の答えのうち、連続日数に残すのは「消したときに印が付いていなかった問題」の答えだけでよいか（印の付いた問題の答えは今も数えないので、消したあとも数えない）
- [ ] 2. 確認のダイアログの「…and their records will be deleted. This can't be undone.」を変えるか。記録は身についている具合や正答率からは消えるが、連続日数には残る。変えるなら文言の案を決める（例：今のまま／「Your day streak is kept.」を足す）
- [ ] 3. Issue にある「印の付いた問題の取り込み直し」は、今回の範囲に入れるか。印の付いた問題への答えは今も連続日数に数えていないので、取り込み直して記録が消えても、連続日数は変わらない。今回は Manage の削除だけにしてよいか
- [ ] 4. 消した問題と同じ ID の問題を取り込み直したとき、今までどおり、まだ解いていない新しい問題として扱ってよいか（消す前の記録は、身についている具合などに戻らない）
- [ ] 5. `docs/overview.md` の「消した問題の記録も一緒に消える」を、「連続日数には残る」ように書き直してよいか
