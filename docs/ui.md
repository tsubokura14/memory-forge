# 見た目の決まり

## トークン

- トークンファイル：`src/styles/tokens.css`（Tailwind には `src/styles/globals.css` で登録する）
- コードでもプロトタイプでも、トークンにない値（`p-[13px]`、`#3366ff` など）を使わない
- 余白はトークンファイルに書かず、Tailwind の既定の余白（`p-4` など）をトークンとして使う
- コードの色（code-*）とコールアウトの一部の色は、kinari-md のトークン（`kinari-md/tokens.css`。`src/styles/globals.css` で読み込む）が持つ。memory-forge のトークンファイルには書かない

## 雰囲気

「紙と江戸紫」。md-leaf（「紙と若葉」）と同じ人が作ったシリーズのアプリに見えるように、地・文字・枠・muted・角丸・影・ダークモードの色、画面の部品の書体、アイコン、ロゴの作りを md-leaf に揃える。
アプリごとに分けるのは、差し色（memory-forge は江戸紫、md-leaf は若葉の緑）と、読むもの以外の書体（memory-forge はコードの等幅）だけ。
地は生成りの紙の色で、白いカードは使わない。面は地と同じ色にし、枠で囲む。

## ライトモードとダークモード

- 設定画面で system / light / dark を選ぶ。最初は system（OS の設定に合わせる）。選んだ値は端末ごとに覚える
- 両方のモードで、同じ名前のトークンを使う（モードごとに値だけが変わる）。モードごとに別のトークンを書き分けない

## 色の使い分け

- 色の値は md-leaf に揃える（ライトもダークも）。memory-forge だけにあるのは、差し色の江戸紫（accent）、炎の弁柄色（flame）、border-strong
- 差し色は江戸紫の1色だけ。ふだんの画面に出る色は、地・文字・muted・accent だけにする。例外は連続日数の flame だけ
  - 炎は暖かい色でないと「灯す」感じが出ないため。flame はほかの場所では使わない
  - success・danger は答え合わせ（Solve・Result）と、帯（誤り・終わったこと）・取り消せない操作・取り込む前の確認だけ、warning は不備の印だけに使う
  - 解説のコールアウトの中は、kinari-md の色のまま（note・info は info、tip は success など。md-leaf と同じ）。info はコールアウトの中だけで使う

| トークン | 使う場面 |
| --- | --- |
| bg | 画面の地。上のバー、下のボタンの帯、ダイアログの地も bg。地の上に乗せる面も bg にし、枠で囲んで見せる |
| surface | 選択肢のカードの地、押せるものに指を乗せたとき、読み込み中の枠、種類の札の地 |
| border | 区切り線と枠。身についている具合の、まだ解いていない問題 |
| border-strong | 身についている具合の、最後に間違えた問題（muted より薄く、border より濃い灰色） |
| text | 本文 |
| muted | 補足の文字（パンくず、問題番号、選択肢の記号、身についている具合の数など） |
| accent / accent-soft | 画面の主な操作、選んでいるもの、リンク、ロゴ、今の問題。主な操作のボタンは1画面に1つだけ。soft は指を乗せた・選んでいる選択肢の地 |
| on-accent | accent の地の上の文字 |
| success / success-soft | 正解と、終わったこと。soft は正解の選択肢や結果の帯の地 |
| danger / danger-soft | 不正解と、誤り、取り消せない操作。soft は選んで間違えた選択肢や誤りの帯の地 |
| warning / warning-soft | 不備の印と、解き終わりの結果の Topic の線の「前は正解したのに今回間違えた」 |
| overlay | ダイアログを出している間の、後ろの画面を暗くする色 |
| flame | 連続日数の、今日答えたときの炎と文字。不備の印の warning とは分ける |
| info | 解説のコールアウト（note・info）の色。ふだんの画面には出さない |
| code-bg、code-line | コードブロックの地・行番号。kinari-md のトークン |
| code-keyword、code-string、code-comment | コードの色分け（md-leaf と同じ3色）。kinari-md のトークン。ほかの言葉の種類とコードの文字は text の色 |

- -soft の色は、元の色を地（bg）に混ぜて作る（割合はトークンファイル）

## 余白と並べ方

- 中身は1列。幅は、PC でも読みやすい幅で止め、画面の真ん中に置く
- 対応する画面の幅：PC が中心。スマホの幅（390px ほど）でも崩れないようにする
- 選択肢は、PC でもスマホでも1列で縦に並べる
- 角の丸みは sm と md の2つ（md-leaf と同じ）

## 文字

- 書体は3種類で、md-leaf と同じ並びにする。OS の書体を先に並べ、端末にない書体だけを Web フォントで配る（Noto Sans JP・Noto Serif JP・Geist Mono）
  - ui（画面の部品：ボタン、一覧、ラベル、数字、見出し、パンくず、選択肢の文）：ヒラギノ角ゴ → 游ゴシック UI → Noto Sans JP（md-leaf の font-ui）
  - body（読むもの：問題文・解説）：ヒラギノ明朝 → 游明朝 → Noto Serif JP（md-leaf の本文）。行の間を広めにする
  - mono（コードだけ）：OS の等幅（ui-monospace → SFMono-Regular → Consolas）→ Geist Mono
  - 文の中のコードを、地の色だけでなく文字の形でも見分けられるように、文章とコードで書体を分ける
  - 数字は幅をそろえる設定（`tabular-nums`）で縦にそろえる。等幅の書体は使わない
- 太さは、ふつう（400）と太字（700）の2つ（md-leaf と同じ）。太字にするのは、アプリ名、画面の見出し、枠の外の上の小さな見出し（「科目」「続きから」など）、主なボタンの文字、Result の得点
- 大きさは xs・sm・base・lg の4段階（md-leaf の画面の部品と同じ段階）。見出しは lg まで
- display の大きさ（4段階の外）は、解き終わりの結果の得点だけに使う（ひと目でわかるように）。書体は ui

## アイコン

- アイコンは、md-leaf と同じ線のアイコン：24 の方眼、線の太さ 2、線の端と角は丸。形は Lucide のものを書き写す（`src/components/icons.tsx`。先頭のコメントに Lucide の著作権とライセンス（ISC））
  - 使う形：check、x、flag、arrow-left、arrow-right、chevron-right、chevron-left、chevron-down、book-open、external-link、trash-2、flame、hammer
  - 大きさは文字と同じで、色は文字と同じ色にする
- 文字の記号（✓ ✗ ⚑ ← → › ▸ など）は使わず、アイコンを置く
  - 文字の記号は、書体に入っていないと別の書体で表示され、画面の雰囲気に合わないため
- 炎は、灯ったら同じ形を塗りつぶす（灯らないときは線だけ）

## 部品の使い分け

- ロゴ：hammer のアイコン（傾けない）を accent の色で、アプリ名（ui の太字）と並べる（md-leaf と同じ「アイコン＋アプリ名」の作り）
  - アプリ名の forge（鍛える）から。単純な形なので、上のバーの小さな大きさでもつぶれない
  - Login では大きく（lg）、アイコンを上に置いて縦に並べる。上のバーでは小さく（sm）、横に並べる
- ボタン
  - 主な操作：accent の地と太字の文字。1画面に1つ
  - ほかの操作（飛ばすなど）：枠だけ。下に固定した操作の中では、主な操作より小さい muted の文字にする
  - 不備の印：枠のない文字だけのボタン。指を乗せると warning の色。押したあとは warning-soft の地と warning の文字の「印を付けた」
  - 絞り込みの切り替え（Manage の不備の印）：枠だけのボタン（muted の文字と flag の印）。押している間は warning の枠・warning-soft の地・warning の文字
  - 脇の操作（上のバーのログアウト）：枠のない muted の文字だけのボタン
  - 帯の中の操作（読み込みや保存のエラーのもう一度）：帯と同じ色の枠と文字のボタン
- 選択肢（Solve）：枠線を付けず、surface の地だけのカード（角は md、内側の余白は左右 px-4・上下 py-3）。状態は地の色で出し、地の色はゆっくり変える
  - 答える前：ふつうは surface、指を乗せると accent-soft、選んでいるものは accent-soft の地で、記号を accent で塗りつぶす
  - 記号（A・B…）：単一選択は丸、複数選択は四角。枠線は付けず、bg の小さな面に太字の文字を置く。ふつうは muted の文字、選んでいるものは accent の面に on-accent の文字
    - 丸と四角を、ラジオボタンとチェックボックスの見分け方に合わせるため
  - 問題の上の種類の札は「1つ選ぶ」「すべて選ぶ」。surface の地で、枠線は付けない
  - 行の右端には何も置かない
- 答え合わせのあと：正解の選択肢は success-soft の地、選んで間違えた選択肢は danger-soft の地。ほかは surface のまま。結果は、問題の上に帯で出す（「正解」、または「不正解。答えは A, B」）
  - 記号もカードと同じ色みの面にする：選んで正解は success を 30% の面、選ばなかった正解は success を 15% の面、選んで間違えたものは danger を 30% の面で、文字はそれぞれ success・danger。ほかは答える前のふつうのまま
  - 答えたあとの状態は、見た目は変えず、読み上げ用の見えない文字（「選んだ答え・正解」「正解」「選んだ答え・不正解」）でも伝える
  - ほかの選択肢を薄くしないのは、答えたあとに選択肢のコードを見比べられるようにするため
- 問題と選択肢の区切り：問題（問題文とコード）は囲まずに地の上に置き、選択肢の前に「1つ選んでください」（単一選択）か「当てはまるものをすべて選んでください」（複数選択）の見出しを置く
- 選択肢の中のコードブロック：行番号は付けず、border の枠で囲む。スマホの幅では、記号を上の行に置き、コードを幅いっぱいに出す
  - 選択肢のカードの地（surface）と code-bg が同じ色で、枠がないとコードブロックの境目が見えないため
- 上のバー：bg の地。ロゴ（ホームへ戻る）とログアウトだけを置く。設定画面へは Home の「設定」のリンクから行く。画面の行き来は、Home と、各画面の左上の戻るリンクで行う。解く画面だけは、やめると進み具合を置く
  - Login には上のバーを出さず、カードの上にロゴを出す（ログアウトが意味を持たないため）
- 各画面の上：左上に戻るリンク（arrow-left の印と行き先の名前を muted で）、その下にパンくず（muted の小さな文字）と見出しを置く
- 下に固定した操作：解く画面と結果の画面は、主な操作のボタンを画面の下に固定し、幅いっぱいに大きく置く。帯の地は bg
  - スマホで、親指で押しやすくするため
- 答えたあと：問題と解説を1画面に並べず、下のボタン（解説を見る / 問題に戻る）で切り替える
- 選ぶもの：一覧から1つ選ぶもの（Topic）は、丸の付いた行。少しの中から1つ選ぶもの（順番、問題数、テーマ）は、横に並べたボタンで、選んでいるものだけを bg の地にする
- プルダウン（Manage の科目と Topic）：ブラウザの select は使わず、押すと下に選ぶものの一覧を開く。開いている間は枠を accent にし、右の印（chevron-down）を上向きにする
  - 一覧の中の行：選んでいるものは accent-soft の地と accent の文字で、左に check の印。行の右に、不備の印の数（あれば warning）と問題数を出す。「すべての Topic」は一番上に置き、ほかと区切り線で分ける
  - 数が多いときは、一覧の高さを止めて中をスクロールする
  - ブラウザの select では、開いたときの見た目を変えられず、問題数などを並べられないため
- 浮かせて重ねるもの（プルダウンの一覧、ダイアログ）：浮かせる影を付ける（md-leaf と同じ）。ほかの部品には影を付けない
  - 下の一覧の上に重なっても、境目がわかるようにするため
- ダイアログ：bg の地。後ろの画面を overlay で暗くする。Esc はダイアログを閉じる側のボタンと同じにし、外側を押しても閉じない
- ページ（Manage の問題の一覧）：50問ずつ。絞り込みと一覧の間に、左に何問目からかの範囲、右に前後のボタンとページの番号を置く。番号は、最初・最後・今のページの前後だけを出し、間は「…」にする。今のページは accent の地。スマホの幅では番号を出さず、前後のボタンの間に「4 / 10」と出す。1ページで収まるときは、前後のボタンと番号を出さない
- 一覧：枠で囲んだ行を、区切り線で並べる。数（問題数、正答率など）は右にそろえる
- 枠の外の上の見出し（「科目」「続きから」「アカウント」など）：muted の太字の小さな文字
- 設定の枠（Settings）：枠の外の上に見出しを置く。枠の中は、左に決まった幅のラベル（muted の小さな文字）、右に値や操作を置き、項目ごとに区切り線で分ける。説明の1行は、ラベルの列から始めて、項目の下に muted の小さな文字で出す
- 今の身についている具合（Home の科目、Setup の Topic）：細い線を、最後に正解した問題（accent）・最後に間違えた問題（border-strong）・まだ解いていない問題（border）の割合で塗り分ける。線の下に「正解 30 · 不正解 10 · まだ 8」と数を出し、右に % を出す。まだ1問も解いていなければ % は「—」
  - 行の中は、左に名前、その下に線、その下に数（色を付けず muted の小さな文字だけ）。% は行の右（Home では chevron-right の印の左）に、決まった幅で右にそろえる
  - 印の数を出すとき（Setup）は、数の終わりに「· 」と flag の印と数（warning）。数が折り返しても、印と数は分けない
- 問題ごとの正答率（Manage）：数字（75% など）と解いた回数。まだ解いていないものは「—」
- 続きから（Home のいちばん上）：枠で囲んだカード。左上に「続きから」の見出し、右上に連続日数の1行、その下に科目の名前（lg の太字）と「N問がまだ身についていません」（muted）、下に幅いっぱいの主な操作「解きはじめる」
- 連続日数（「続きから」のカードの右上）：炎のアイコンと文字を1行で、xs の大きさで出す
  - 今日答えた：灯った（塗りつぶした）炎と「N日連続」を flame で。まだ：灯らない（線だけの）炎と「N日連続・今日はまだ」を muted で。0日：灯らない炎と「今日解くと連続日数が始まります」を muted で
  - 読み込めなかったとき：muted の「連続日数を読み込めませんでした」
- 解き終わりの結果：上に「解き終わりました」と科目の名前。その下に、得点（正解の数を display の太字、「/ 10問 正解」を lg の muted）、正答率、不正解・飛ばした・不備の印（数えない）の数（muted のラベルと text の数）を並べ、区切り線を引く
  - その下に「Topic ごと」の見出しと、Topic ごとの行（名前、割合の線、得点「3/4」）。線は、正解（success）・前は正解したのに今回間違えた（warning）・それ以外の不正解（danger）の順に塗り分ける。名前は決まった幅（スマホの幅では狭く）に置き、長いときは「…」で切り、線は残りの幅いっぱいに伸ばす
  - 下に固定して、ホームへ戻る（枠だけ）ともう一度解く（主な操作）を横に並べる。戻るリンクは置かない
  - 数える問題が0問（全部に不備の印）のときは、得点を muted の「—」、その下を「数える問題がありませんでした（すべてに不備の印）」にする。Topic ごとの一覧は出さない
- 外のページ（GitHub のドキュメントなど）へのリンク：枠で囲んだ1行にし、左に内容を表す印（説明なら book-open を accent の色で）、真ん中に題と短い説明、右に external-link の印を置く。別のタブで開く
  - アプリの中の画面へ移るリンクと見分けられるようにするため
- 取り消せない操作（削除）：科目と Topic の削除は、それぞれのプルダウンのすぐ右に、trash-2 の印だけの枠のボタンを置く（指を乗せると danger）。Topic が「すべての Topic」のときは、Topic の削除のボタンを出さない。押したら確認のダイアログを出し、消えるもの（問題数、記録）と、取り消せないことを書く
  - 一覧の行の削除（Manage の1問）：行の右に、muted の「削除」を枠のない文字だけのボタンで置く。指を乗せると danger の文字と danger-soft の地
  - 確認のダイアログ：右下にやめる（枠だけ）と削除（danger の地と on-accent の文字）。1つのものを消すときは、何を消すのか（問題文の1行目など）を説明の上に出す。消せなかったときは、ダイアログを閉じずに、ボタンの上に danger の帯を出す
- 不備の印が付いているもの：warning の色で flag の印と数を出す。一覧の行は、warning-soft の地にする
  - Manage の問題の行には、flag の印と「印を外す」を warning の文字のボタンで出し、押すと印が外れる
  - Setup の始めるボタンの上には、印の付いた問題を除いたこと（muted の小さな文字で、印と数だけ warning）
- 書き出しのボタン（Manage）：科目の名前を入れる。印の一覧を見ているときは「Python の不備の印を書き出す」のように
  - 書き出しは科目の単位なので、Topic で絞っていても、その Topic だけを書き出すように見せないため
- 取り込む前の確認：ファイル名 → 科目の名前を出す。まだない科目のときは、success の枠で新しい科目であることを添える
  - 増える・置き換わる・変わらない数は、3つの枠に横に並べ、数字の下にラベルを置く。増えるは success、置き換わるは warning（0なら muted）、変わらないは muted の数字にする
  - 置き換わる問題は、1問ずつ開閉する行にする。行には開閉の印と ID と問題文の1行目を出し、開くと、変わった項目ごとに、前（danger の枠と danger-soft の地）と後（success の枠と success-soft の地）を横に並べる（スマホの幅では縦）。最初の1問だけを開いておく。印の付いた問題の行は、右に warning の flag の印と「印と記録をリセット」
- 中身の幅：ログインは sm の幅のカードにする。ほかの画面は、どれも page の幅で止める
- 問題文・選択肢・解説の本文：md-leaf の本文と同じ、kinari-md の本文の見た目（`kinari-md/body.css`）にする。memory-forge で変えるのは、入れ物ごとの文字の大きさ・書体と、選択肢の中のコードブロックの枠だけ
  - 文字の大きさ：問題文は lg、解説は base、選択肢と取り込む前の確認は sm。書体：問題文・解説は body、選択肢の文は ui、コードは mono
  - 直し方の決まりは `docs/design.md` の「問題文・選択肢・解説の表示」
- コードブロック：code-bg の地で、枠は付けない（選択肢の中だけ枠を付ける）。角は md。問題文のコードには、各行の頭に code-line の色で行番号を付ける（番号の列と区切り線は付けない）
- 文の中のコード：置かれた場所の地に重ねた地で囲む（選択肢のカードや答え合わせの色の上でも見分けられる）
- コードの色分け：キーワード・文字列・コメントの3色（code-keyword・code-string・code-comment）。ほかは text の色。言語の名前は出さない
- 進み具合（解く画面）：上のバーの右に、ここまでの正解の数（success の check の印）、不正解の数（danger の x の印。飛ばしたものを含む）、今の問題の番号（4/10 など）を出す。上のバーの下の端に、答えた割合だけ伸びる accent の線を、画面の端から端まで引く（残りは border）
  - 問題数が多くても（すべてで100問以上など）同じ見た目で済むように、1問ずつの○×は並べない

## 状態の見せ方

- 点線・破線は使わない
- 0件：border の実線の枠の中に、短い説明と、次にすることのボタン（あれば）を出す
- 読み込み中：出てくるものと同じ形の枠を、surface の色で点滅させる
- 読み込みや保存のエラー：danger の帯で出し、右にもう一度のボタンを置く
  - 押して送る操作（ログインなど）のエラーは、もう一度のボタンを置かない（同じボタンをもう一度押せば済むため）
- 取り込むファイルの誤り：danger の帯で「何件の誤りがあり、何も取り込んでいないこと」を出し、その下に、問題・項目・内容を1行ずつ並べる
- 終わったこと（取り込めたなど）：success の帯や枠で出す
- 知らせ（答える前に不備の印を押して次に進んだ）：warning の枠と warning-soft の地の帯に、flag の印と文字

## 文言

- 画面の表記は日本語（`docs/overview.md` の「用語」）。Subject は「科目」、Topic は「Topic」のまま
- ボタンとラベルは短く（「次の問題へ」「解説を見る」など）。帯の文言は、「。」で終える文の形にする（「この Google アカウントは紐づけられていません。」など）
- 取り込みの誤りの項目の名前（text・correct など）は、ファイルの項目の名前なので英語のまま
- 問題文・選択肢・解説は、取り込んだデータの言葉のまま出す（日本語のことも英語のこともある）
