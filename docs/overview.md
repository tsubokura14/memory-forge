# 概要

## 目的

資格試験などの勉強のために、Claude に作らせた選択式の問題を解くアプリ。プログラミング系の題材も扱えるように、問題文・選択肢・解説にコードを色付きで表示する。
ポートフォリオとして公開する。

## 使う人

- 自分ひとり。PC のブラウザで解くのが中心で、スマホでもすきま時間に解く
- 公開はするが、ログインできるのは自分のメールアドレスだけ
- いずれ複数人で使うかもしれない
- ひとりで使うがログインを作る理由：PC とスマホで記録を共有するため／ポートフォリオとして公開しても、他人に問題や記録を見られないようにするため／いずれ複数人で使うときに備えるため

## 主な機能

- ログイン：自分のメールアドレスだけが通る。新しい登録はできない
- 問題づくり：このプロジェクトの中のルール・スクリプト・スキルに従って、Claude Code に問題のファイル（JSON か CSV）を作らせる。ルールなどは公開し、作った問題のファイルは公開しない（Git に入れない）
  - 問題の元はアプリの中身。プロジェクトの中のファイルは作るときの作業場所で、直すときはアプリから書き出したファイルを直して取り込み直す
  - 新しい問題には、今ある問題と重ならない ID を付ける。問題の ID には意味を持たせない
  - 作ったファイルは、次のことを確かめてから取り込む：同じ Subject の中で問題の ID が重なっていない／決まった項目（問題文・選択肢・正解・解説など）がそろっている／正解が選択肢の中にある（単一選択は1つ、複数選択は2つ以上）／コードブロックの書き方が崩れていない
- 問題の取り込み：問題のファイルを、アプリの画面から取り込む。取り込むときにも問題づくりと同じことを確かめ、誤りがあれば、どの問題のどこが誤りかを画面に出し、何も取り込まない（手で直したファイルなど、問題づくりで確かめていないファイルが来ることがあるため）。問題に誤りがあったら、ファイルを直して取り込み直す
  - 同じ Subject の中で ID が同じ問題を「同じ問題」とする。Subject が違えば、ID が同じでも別の問題（ID が偶然重なる範囲を、Subject の中だけに狭めるため）。Topic は ID を持たず、Subject の中の名前で見分ける
  - 同じ問題を取り込み直すと、問題文・選択肢・解説が新しいものに置き換わる。そのとき不備の印は消え（直したはずなので）、記録は残る
- 取り込む前の確認：取り込む前に、新しく増える問題・置き換わる問題・変わらない問題の数と、置き換わる問題の前と後の中身を見せる。「全部取り込む」か「やめる」かを選び、選ぶまでは何も変わらない。ID が偶然重なって、別の問題で古い問題を上書きしないようにするため
- 問題の書き出し：取り込んだ問題を、Subject の単位でファイルに書き出す。書き出したファイルは、そのまま取り込み直せる
- 問題の削除：Subject ごと・Topic ごと・1問ずつ消せる。消した問題の記録も一緒に消える
- 解く：Subject の中の Topic を1つ選ぶか、全部の Topic をまとめて選び、問題数と出題の順番（正答率が低い順を含む）を選んで解く。1つを選ぶ問題・複数を選ぶ問題に答える
- 答え合わせ：1問答えるごとに、正解・不正解と解説を出す。複数選択は、全部合っていたときだけ正解（部分点なし）
- スキップ：どの問題でも、答えずに次へ進める。スキップした問題は不正解として記録する（たまたま正解して記録に残るのを避けるため）
- 記録：問題ごとに正解・不正解を残す。正答率が低い順に出題するために、最初の版から作る
- 不備の印：解いていて誤りに気づいた問題に印を付ける。印を付けると、その問題は答えずに次へ進み、記録には残さない（未回答）。印の付いた問題を一覧で見たり、書き出したりできる。印の付いた問題は出題しない
- コードの表示：問題文・選択肢・解説の中のコードを、言語に合わせて色付きで表示する

あとで作る機能（最初の版では作らない）

- 復習：間違えた問題だけを解き直す
- 間隔をあけた出題：忘れかけたころにもう一度出す
- 問題を取り出す API：Claude Code が、画面からの書き出しを使わずにアプリから問題を取り出せるようにする。ログインとは別に Claude 用の鍵の仕組みが要るので、最初の版は書き出しで済ませる

## やらないこと

- アプリの中で AI を呼んで問題を作らない（問題はこのプロジェクトの中で Claude Code に作らせる）
- 取り込む前の確認で、問題を1問ずつ選んで取り込まない（おかしな問題があったら、ファイルを直してから取り込み直す。ひとりで使うなら、ファイルを直すほうがおかしな ID が根本から直り、画面も簡単になるため）
- スマホアプリ（ストアで配るもの）は作らない。スマホは Web をホーム画面に追加して使う
- 選択式以外の問題（記述・並べ替え・穴埋めなど）は扱わない
- 複数選択の部分点は付けない
- アプリの画面で問題を書き換えない（直すときはファイルを直して取り込み直す）
- 自分以外の人のログイン・新しい登録は作らない
- 問題のまとまりは Subject → Topic の2段まで。それより深くしない

## 用語

アプリの画面の表記は英語にする。

Subject / Topic と呼ぶのは、資格以外の題材にも合い、スマホの狭い画面でも短いため（Category / Subcategory は、タグや種類に見えやすく、Subcategory は長い）。

| 用語 | 意味 |
| --- | --- |
| Subject | 問題のいちばん上のまとまり（例：AWS SAA、Python）。書き出しの単位 |
| Topic | Subject の中の問題のまとまり（例：Networking、Decorators） |
| 問題 | 問題文・選択肢・正解・解説のひとまとまり |
| 単一選択 | 選択肢から1つだけ選んで答える問題 |
| 複数選択 | 選択肢から当てはまるものをすべて選んで答える問題 |
| 解説 | 答えたあとに出す、正解の理由の説明 |
| 取り込み | Claude が作った問題のファイルを、アプリで解ける状態にすること |
| 書き出し | 取り込んだ問題を、ファイルに保存すること |
| スキップ | 答えずに次の問題へ進むこと。不正解として記録する |
| 不備の印 | 解いていて誤りがありそうだと気づいた問題に付ける印。付けた問題は未回答のまま次へ進む |
